# Dashboard de Finanzas Personales - Python

Análisis completo de ingresos, gastos y ahorro mensual 
generado automáticamente con Python.

## Tecnologías
- Python (pandas, matplotlib, openpyxl)

## Contenido
- `finanzas_personal.py` — Script principal
- `dashboard_finanzas.png` — Dashboard con 4 gráficos
- `finanzas_personal_20260527.xlsx` — Reporte Excel con 3 hojas

## Análisis realizados
- Ingresos vs Gastos vs Ahorro mensual
- % Ahorro por mes
- Composición de gastos anuales
- Ahorro acumulado anual
